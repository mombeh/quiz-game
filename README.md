# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## Problem
Many quiz applications lack engagement and do not adapt to different user skill levels, leading to boredom or frustration.

## Solution
This application provides a fast-paced, category-based quiz experience with timed questions, difficulty selection, and detailed result feedback, creating an engaging and personalized learning experience.

## Features
- Category-based quiz
- Timed questions
- Score tracking
- Result summary

## Tech Stack
- React
- React Router
- Context API
- Open Trivia DB API

## What I Learned
- Managing global state
- Handling async APIs
- Implementing timers in React
- Improving UX flow

Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.
